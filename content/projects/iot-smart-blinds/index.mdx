Personal project creating an IoT-enabled automated blind controller that syncs with wake-up alarms and sunset times to optimize natural light for better sleep quality. The system achieved 100% reliability over 30 days of continuous testing.

## Project Overview

**Goal:** Improve sleep quality by automatically opening blinds at wake-up time and closing them at dusk. This personal project tackles a real problem I experienced with light disrupting my sleep schedule.

The system uses smart home integration to detect morning alarms and weather API integration to sync with local sunset times, creating a fully autonomous solution that requires zero manual intervention once configured.

:::tip
This project demonstrates the power of IoT in solving everyday problems. The combination of ESP32, smart home integration, and weather APIs creates a seamless automation experience.
:::

## Electronics & Hardware

The system uses an ESP32 microcontroller paired with an off-the-shelf stepper motor driver. I designed and 3D-printed a custom enclosure to mount the stepper motor to the blind mechanism, utilizing rapid prototyping to iterate through multiple design revisions.

### Key Components
- **Microcontroller:** ESP32 (WiFi-enabled)
- **Motor Driver:** Stepper motor driver board
- **Actuator:** NEMA 17 stepper motor
- **Enclosure:** Custom 3D-printed PLA housing
- **Power Supply:** 12V DC adapter

The mechanical coupling required careful design to transfer torque from the stepper motor to the existing blind mechanism without modification to the window assembly. Multiple iterations were needed to achieve proper fit and torque transmission.

:::warning
When designing the mechanical coupling, ensure the stepper motor has sufficient torque to handle the blind weight. Initial prototypes failed due to torque limitations before upgrading to NEMA 17.
:::

## Firmware

The embedded firmware handles WiFi connectivity, time synchronization, API communication, and automation logic.

```cpp
// C++ (Arduino) Firmware
void setup() {
  // Connect to WiFi
  WiFi.begin(ssid, password);
  
  // Sync time with NTP server
  configTime(gmtOffset, daylightOffset, ntpServer);
  
  // Fetch sunset time from Weather API
  sunsetTime = fetchSunsetTime();
}

void loop() {
  // Check SmartThings for morning alarm trigger
  if (alarmTriggered()) {
    openBlinds();
  }
  
  // Close blinds at sunset
  if (currentTime >= sunsetTime) {
    closeBlinds();
  }
}
```

The firmware uses non-blocking code to maintain responsiveness and includes error handling for network failures and API timeouts.

## Connectivity & Integration

The firmware connects via Wi-Fi to fetch real-time sunset times from a Weather API and syncs time with an NTP server. Integration with Samsung SmartThings enables the system to detect my morning alarms.

### Control Flow
**Online Database → IFTTT → SmartThings → ESP32**

- **Weather API:** Fetches daily sunset time based on GPS coordinates
- **NTP Server:** Provides accurate time synchronization

:::info
The modular architecture makes it easy to add new triggers or actions. For example, you could integrate weather forecasts to keep blinds closed on extremely hot days or integrate with other smart home devices.
:::
- **IFTTT:** Acts as middleware between alarm apps and SmartThings
- **SmartThings:** Sends webhook triggers to ESP32

This architecture allows the system to work with any alarm clock app connected to SmartThings, making it flexible and user-friendly.

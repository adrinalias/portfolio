Academic project designing and building a trebuchet using computer-controlled manufacturing. Achieved the target of launching a penny exactly 6 feet using only interference fits for assembly.

## Project Objective

Course project challenge: Design and build a trebuchet using computer-controlled manufacturing techniques. The objective was precise:
- **Projectile:** One penny
- **Counterweight:** Quarters only
- **Target Distance:** Exactly 6 feet
- **Assembly Constraint:** Interference fits only (no fasteners or adhesives)

This project combined mechanical design, precision manufacturing, and practical engineering iteration to achieve the exact performance target.

## Design & CAD

Designed the complete trebuchet in SolidWorks for manufacture using laser-cut wood components and 3D printed/COTS (Commercial Off-The-Shelf) parts. Applied **GD&T (Geometric Dimensioning and Tolerancing)** principles to ensure proper fit and function.

### Design Decisions
- **Frame:** Laser-cut wood for accuracy and cost-effectiveness
- **Pivot Points:** 3D printed bearings for smooth rotation
- **Arm:** Optimized length ratio between counterweight and projectile sides
- **Sling:** COTS string and pouch mechanism
- **Release Mechanism:** Adjustable pin for fine-tuning launch angle

The SolidWorks model served as both the design tool and the manufacturing documentation, with all parts dimensioned directly from the virtual assembly.

## Manufacturing & Assembly

All structural components were laser cut from wood based on precise CAD drawings. The unique constraint: **assembly using only interference fits**—no fasteners allowed.

### Interference Fit Strategy
This required extensive tolerancing studies to determine the exact interference values needed for secure joints without adhesives or mechanical fasteners. Key considerations:
- **Material Properties:** Wood grain direction affects compression behavior
- **Interference Amount:** Too loose = parts fall apart; too tight = parts crack during assembly
- **Environmental Factors:** Humidity changes affect wood dimensions
- **Assembly Sequence:** Parts must be assembled in specific order

Multiple tolerance iterations were tested on scrap material before finalizing the manufacturing drawings.

## Testing & Validation

Built an initial prototype to test the design and validate simulation data. Used test results to correct and refine the final design, ensuring the penny would land at exactly 6 feet.

### Iterative Process
1. **Initial Build:** First prototype missed target by 18 inches
2. **Analysis:** Measured actual arm swing angle and release point
3. **Adjustment:** Modified counterweight position and sling length
4. **Second Build:** Within 6 inches of target
5. **Fine-Tuning:** Adjusted release pin angle
6. **Final Build:** Achieved exact 6-foot target distance

The testing phase revealed that small changes in the release angle had significant effects on range, requiring precise control of the trigger mechanism.

## Results

The final trebuchet successfully launched the penny to the target distance without breaking any design requirements. The project demonstrated effective use of:
- **DFMA Principles:** Design optimized for laser cutting and 3D printing
- **Simulation Validation:** CAD models predicted real-world performance
- **Precision Manufacturing:** Tight tolerances achieved through computer-controlled processes
- **Engineering Iteration:** Prototype testing drove design refinement

### Key Learnings
- Importance of tolerance analysis for interference fit assemblies
- Value of rapid prototyping for validating design assumptions
- Impact of manufacturing process selection on part quality
- Need for adjustment mechanisms when targeting exact performance specs
